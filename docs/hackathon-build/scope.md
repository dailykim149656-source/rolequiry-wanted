# Scope

Rolequiry Wanted Edition. 원티드 AI Championship 2026 예선 제출 범위.

## Problem

입사 후에야 역할·업무환경·의사결정 방식이 공고와 다르다는 걸 알게 된다. 문제는 회사 폭로가 아니라, 회사와 지원자의 기대를 채용 전에 맞추지 못하는 것이다.

## Audience

원티드에서 공고를 보고 지원 여부를 고르는 사람. 그리고 로그인 없이 배포 링크를 여는 심사자·투표자.

## In

한 개 공고의 Job Fit을 깊게 확인하는 standalone web.
원티드 URL을 대표 입력으로 하고, 다른 URL과 텍스트 붙여넣기를 받는다.
공고 원문 quote claim, 사용자 중요도, 코드가 고르는 다음 조사 항목, 한 항목 공개 웹 조사, verifier, 면접 질문.
API 없이도 보이는 샘플 데모.

## Out

계정, 결제, BYOK, 이력서, 자소서, 자동 지원, 회사 점수, 여러 회사 비교, 리뷰 사이트 크롤러, WebMCP를 메인 UX로 쓰는 일.

## Constraint

접수 2026-09-18, 제출 2026-09-20. 배포 링크는 예선 투표 10-05까지 열려 있어야 한다.
기존 WebMCP 결정 코어는 유지하고, 추출·조사·검증만 제품 안에 넣는다.

## Success

심사자가 링크를 열고 샘플 또는 실제 공고로 claim → 조사 → 입사 전 확인 질문을 한 번에 끝낸다. 근거가 없으면 제품이 단정하지 않는다. 회사 점수나 거절 권유가 없다.
